# Carpeta de marca

Aquí viven los archivos originales del logo de IdEducando. No se redibujan ni se retocan: si hace falta otro tamaño o formato, se genera una copia a partir de estos.

| Archivo | Qué es | Cuándo usarlo |
|---|---|---|
| `simbolo.svg` | Símbolo: la bombilla con un niño dentro, en vectorial | Icono de la web (favicon), sellos y tamaños pequeños sobre fondo claro |
| `simbolo-oscuro.svg` | El mismo símbolo con colores aclarados | Sobre fondos oscuros, como el marino |
| `08-logo-vertical-transparente.png` | Símbolo encima y nombre debajo (1600 × 1560 px) | Portadas de PDF, perfiles de redes y carteles |
| `09-logo-horizontal-transparente.png` | Símbolo a la izquierda y nombre a la derecha (2400 × 700 px) | Cabecera de la web y pies de página de los materiales |
| `10-logo-horizontal-blanco.png` | Versión horizontal con el nombre en blanco (2400 × 700 px) | Sobre fondos oscuros |
| `11-simbolo-transparente.png` | Símbolo en PNG (1024 × 1024 px) | Donde no se acepte SVG (Notion, redes) |

SVG significa *Scalable Vector Graphics*: una imagen hecha de trazos matemáticos, como un plano de planta, que se ve nítida a cualquier tamaño. PNG es una imagen de píxeles, como una foto, y con fondo transparente.

## Colores y letras

- Azul `#2F6FD6`, verde `#1FA67A`, coral `#E8553E`, morado `#8C4FB8`, amarillo `#F6C12E`, naranja `#F5961F`.
- Marino `#1E2B55` para el texto y crema `#FFF6E6` para los fondos.
- Outfit para el nombre y los títulos, Young Serif para el lema y Atkinson Hyperlegible para los textos.

En la web, el verde y el coral no se usan para texto sobre crema porque no llegan al contraste mínimo AA (nivel medio de las pautas de accesibilidad WCAG). Para enlaces se usa un azul un punto más oscuro, `#2B6CD5`.
